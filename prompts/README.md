# Prompts — MCP learning pack

Ready-to-paste prompts for tutors and study partners. Ground answers in the **public** MCP specification revision **2026-07-28**.

## Golden rule

Never paste API keys, tokens, cookies, private calendars, `.env` files, PEM/P12 material, or service-account JSON into models. Redact hostnames if they embed credentials. Describe layouts with abstract roles (calendar MCP, search MCP) and no secret values.

## Categories

| File | Use when |
|------|----------|
| `01-briefing.md` | Need a tight 2026-07-28 overview |
| `02-socratic.md` | Drill understanding with questions only |
| `03-migration-drill.md` | Practice 2025-11-25 → 2026-07-28 upgrades |
| `04-security-review.md` | Threat-model servers, MRTR state, auth registration |
| `05-skills-vs-mcp-lab.md` | Map skills vs MCP vs a thin CLI without leaking secrets |

## Suggested study order

1. Briefing
2. Socratic (Week 1–2 topics) and flashcards in the console
3. Migration drill and quiz Weeks 2–3
4. Security review and quiz Week 4
5. Skills vs MCP lab, then a short migration memo
